# 实机验证

验证日期：2026-11-10。

| 环境 | 实测值 |
| --- | --- |
| 平板 | Xiaomi Pad 7 |
| 系统 | Android16 / API36 |
| 固件 | HyperOS OS3.0.306.0.WOZCNXM |
| 客户端 | Windows物理WLAN接口 |

| 项目 | 结果 |
| --- | --- |
| 5GHz上游 + 2.4GHz热点 | 上游5745MHz；下游实测2412、2437、2462MHz |
| 5GHz上游 + 5GHz热点 | 上下游5745MHz；客户端5GHz/149信道 |
| 自动频段 | BAND_AUTO请求，系统本次选择5745MHz |
| 客户端联网 | 自动DHCP与网关DNS；直接UDP DNS rcode=0、TCP成功、HTTPS200 |
| 双向切频 | 5→2.4→5，同一Helper/TAP会话，DNS和HTTPS均通过 |
| 重启恢复 | 两次真实重启；原Helper已结束、无线调试为0；打开应用点击启动后本机恢复成功 |
| 快速取消后重开 | 恢复期间启动→150ms后停止→500ms后重开，清理先于新共享建立 |
| 完整停止 | P2P group=null、接口DOWN、无TAP及对应转发规则；再次启动联网正常 |

网络验证将DNS和HTTPS套接字绑定物理WLAN接口及其地址，避开客户端原有代理/TUN。重启后的操作仅打开应用、点击按钮和读取状态，没有通过电脑授予权限或启动Helper。

这些共享与重启测试对应1.1核心实现。首个公开版1.1.1保留同一共享链路，新增通用构建、随机首次密码、开源资料，并将最低系统版本对齐到实际使用的API36。

当前实机覆盖上述小米平板7固件。其他型号需同时提供小米P2P NAT服务及硬件跨频并发能力；项目尚未记录其他型号的通过结果。
